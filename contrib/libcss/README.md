# LibCSS

LibCSS is a CSS parser and selection engine. It aims to parse the forward compatible CSS grammar.

## API documentation
Currently, there is none. However, the code is well commented and the public API may be found in the "include" directory.

## Wisp Fork Status (2026)
Wisp maintains a diverged fork of LibCSS to support modern standards:
- **CSS Grid**: Integrated support for Grid layout properties.
- **CSS Flexbox**: Integrated support for Flexbox properties.
- **CSS Variables**: Support for custom properties and the `var()` function.
- **calc()**: Support for the `calc()` value function.
- **tab-size**: Native support for the `tab-size` property.
