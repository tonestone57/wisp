Wisp Project
===============

The Wisp project is developing a document browser for the World
Wide Web. It maintains the spirit of a lean, portable browser while
bridging the gap to modern standards (CSS Grid, Flexbox, ES2023+ JS).

Wisp is very modular and built from many component libraries. Recent
modernization (as of 2027) has unified the rendering backend around
**Blend2D** and transitioned the JavaScript engine to **QuickJS-ng**.

While bridging the gap to modern standards, the project acknowledges the core [Architectural Boundaries](architectural-boundaries.md) of lightweight web engines when compared to multi-gigabyte browser suites.

Wisp browser is open source and is licensed under the GPLv2 (with
OpenSSL exception). Many of the supporting libraries are under a MIT
licence.
